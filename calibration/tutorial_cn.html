独立标定程序使用教程

本教程将引导您完成从程序下载到机械臂标定完成的全流程。按照以下步骤操作，即可顺利完成机械臂的视觉标定，实现用鼠标直接操作手机屏幕。

下载与解压

从官方仓库下载的完整压缩包约160MB。后续更新过教程，所以实际大小略有出入。找一个空间充足的盘符，拷贝进去并解压。建议单独建立目录，例如 D:\RobotArmKit。

启动主程序

双击运行 RobotArmCalibration.exe，会弹出命令行窗口显示基本信息。

  • • 首次运行：自动安装机械臂硬件驱动
  • • 非首次运行：跳过驱动安装，直接进入主界面

程序顺利启动后，会显示摄像头画面，右侧是信息面板。

特别注意：程序启动需要监听12345端口，用于与手机端通信，如果防火墙阻止，必须允许才能继续使用。

图26 · 防火墙放行

网络配置（关键步骤）

手机程序和电脑程序需要通信互传数据才能精确标定，因此必须确保双方使用正确的内网IP。

查看电脑内网IP

打开电脑的网络设置，点击"属性"，找到 IPv4 地址并记录。示例：192.168.31.83

图12 · 查看电脑内网IP
图13 · Pydroid 3代码界面
修改手机代码中的IP

回到手机Pydroid 3界面，手指上划到代码283行附近，将IP改为您的电脑实际内网IP。

运行脚本

改好后，点击右下角的运行标志（▶）。手机屏幕4个角落显示4个圆点。电脑端提示"手机已连接"。

图14 · 修改IP并运行
6

角点识别与确认

程序一直在寻找4个角落的圆点。已识别的角点会显示"稳定"。如果反光或有干扰，可能显示某个点"跳动"。

图15 · 手机4个角点 + 电脑端已连接
确认4个角点位置
  1. 光标是十字形，尽量让中心点落在圆心中再点击
  2. 程序自动找到的角点用蓝色圆圈标记
  3. 您用鼠标确认的点用红色圆圈标记
  4. 4个角点全部标记完成后，提示"所有点都已锁定"
图16 · 角点稳定状态
⚠按回车键确认锁定。只有按了回车才是真正的确认。
图17 · 确认角点位置

触摸笔操作

• 按下：按空格键
• 抬起：再次按空格键

⚠重要：不要在触摸笔按下的状态下移动机械臂！必须先抬起再移动。

默认下按深度为9mm。触摸笔具备形变功能，手机正常摆放不会造成伤害。

移动到角点上方

控制机械臂依次移动到4个圆点上方，按下-抬起触摸笔，尝试点击圆点。每次点击后，手机屏幕显示"上次点击"坐标。

每点击正确一个点，显示"已确认 N/4"。

图22 · 点击确认坐标

4个点都正确点击后，机械臂自动复位，进入阶段4。

验证标定结果

手机画面显示随机8个点。在电脑端用鼠标点击看到的点，机械臂自动移动到对应位置按下并抬起。

  • 电脑画面中显示白色圆点标记点击位置
  • 右侧面板显示：点击位置、期望目标、实际坐标
  • 通常误差不超过几个像素
图23 · 验证标定结果
9

保存与复用

保存

点击"退出（ESC）"，然后在电脑端按 Q 键退出。标定结果自动保存到 calibrations 目录。

复用已有标定

重新启动时，CMD窗口提示发现标记记录：

  • 输入 1 + 回车：采用已有标定结果
  • 输入 0 + 回车：重新标记一次
直接使用

选择已有标定后，手机不再需要运行Pydroid 3。可以直接在电脑画面中点击各个位置，就像用手指操作手机一样。

常见问题

请检查您的系统是否为 Windows 10 或 Windows 11，并确认是否有杀毒软件阻止了硬件驱动的安装。
请依次检查以下三项：
1. 机械臂是否正常通电（电源插口附近蓝灯常亮）
2. 机械臂本身的 蓝色USB线 是否正确接入电脑USB插口
3. 机械臂顶部摄像头延伸出的黑色USB线是否正确接入电脑USB插口
全部确认后，再次启动程序。
Pydroid 3 右上角有个文件夹图标，点击可选择'open'。
找到你从电脑传输过来的 phone_calibration_app.py 文件。
（如果还没传到手机，可通过微信/QQ/USB数据线等方式从电脑发送该文件到手机）
如果使用不明白可以网络搜索 Pydroid 3 使用教程。
或将你遇到的实际问题发送给作者 hamlet0168@163.com
标定结果保存在解压后根目录中的 calibrations 目录下。
可以同时保存多个标定结果，假设你多次重新标定的话。你可以利用这个特性，给每个手机（比如 iPhone 或华为手机）各配备一套标记文件。
启动程序时，所有标记都会列出来，你可以随意选择使用哪个标记文件。
输入对应标记文件的数字并回车即可。
标记文件都是以时间格式命名的 json 文件，比如 calib_20260529_143311.json。
可以，全部删除的话，再次启动程序就需要重新标记了。
或者每次你重新调整了手机固定装置，哪怕是微小调整，都应该重新标记，原来的标记文件就没有意义了。
