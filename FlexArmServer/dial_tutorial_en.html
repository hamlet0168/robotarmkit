🤖 Robotic Arm Automation · Phone Dialing

Automated Phone Dialing with FlexArm

This tutorial shows you how to configure the robotic arm to automatically dial any phone number. Once set up, you can reuse the same script over and over — just change the phone number each time.

✓

Requirements

Before you begin, make sure:

  • • RobotArmServer.exe is running
  • • Camera is focused on the phone screen
  • • Calibration is completed
  • • Phone dialer app icon is configured in app_desktop.yaml (so run_app can launch it)
1

Write the Dialer Page Configuration

Create a page config file at scripts/configs/app_phone_dialer.yaml. This tells the program how to recognize the dialer app's different screens.

Minimal config (dialer page only)

If you only need to dial numbers (no call monitoring), the config can be very simple:

ℹThe must_features only need 2-3 digit icons — these are the "gate" to identify the page. The rest go in features as candidate pool. The dialer will match enough icons to confirm it's on the keypad screen.
3

Write the Dial Script

Create a YAML script that defines the dialing flow. Here is a minimal example:

Minimal script — dial and hang up
name: auto_dial
description: "Auto dial a phone number"

steps:
  # 1. Launch the Phone app
  - action: run_app
    app_name: Phone

  # 2. Wait for app to load
  - action: wait
    seconds: 2

  # 3. Dial the number
  - action: dial_number
    number: "13258652185"
    interval: 0.8

  # 4. Tap the green call button
  - action: click_icon
    path: icons/phone/call.png
    mask: false

  # 5. Wait for the call to connect
  - action: wait
    seconds: 10

  # 6. Hang up
  - action: click_icon
    path: icons/phone/hang_up.png
    mask: false
Advanced script — with page detection + state monitoring

This version uses switch_page to detect which screen we're on and handles different states:

name: smart_dial
description: "Smart dial with page state detection"

steps:
  # 1. Launch the Phone app
  - action: run_app
    app_name: Phone

  # 2. Wait for app to load
  - action: wait
    seconds: 2

  # 3. Loop: detect page state and act accordingly
  - action: loop
    count: 3
    steps:
      - action: switch_page
        config: scripts/configs/app_phone_dialer.yaml
        cases:
          # We are on the dial pad — enter the number
          dial_pad:
            - action: log
              message: "On dial pad, entering number..."
            - action: dial_number
              number: "13258652185"
              interval: 0.8
            - action: click_icon
              path: icons/phone/call.png
              mask: false

          # Call is active — wait then hang up
          in_call:
            - action: log
              message: "Call connected, waiting..."
            - action: wait
              seconds: 10
            - action: click_icon
              path: icons/phone/hang_up.png
              mask: false

          # Unknown page — swipe or go back
          default:
            - action: log
              message: "Unknown page, going back"
            - action: go_back
            - action: wait
              seconds: 1
Using click_icons for manual dialing

Alternatively, you can dial digits one by one using click_icons — this gives more control:

  - action: click_icons
    paths:
      - icons/phone/num1.png
      - icons/phone/num3.png
      - icons/phone/num2.png
      - icons/phone/num5.png
      - icons/phone/num8.png
      - icons/phone/num6.png
      - icons/phone/num5.png
      - icons/phone/num2.png
      - icons/phone/num1.png
      - icons/phone/num8.png
      - icons/phone/num5.png
    interval: 0.8
⚠The dial_number action is simpler and recommended for most cases. It automatically maps each digit character to the corresponding icon file. click_icons is useful when you need special handling per digit.
4

Run the Script

Once the script is written, execute it via the API:

Via API
# Start the dial script
POST /api/run_script {"path": "scripts/auto_dial.yaml"}
# Returns: {"ok":true,"data":{"script":"...","status":"started"}}

The robotic arm will:

1. Launch the Phone app via run_app (auto-navigates to desktop, finds Phone icon, taps it)

2. Wait for the dial pad to appear

3. Dial each digit one by one (each digit is a template match + click)

4. Tap the green call button

5. Wait, then hang up

6. Auto-reset arm position when done

Monitoring execution
# Check script status
GET /api/script_status
# Returns: {"ok":true,"data":{"running":true,"current_script":"scripts/auto_dial.yaml"}}

# Check detailed progress
GET /api/script_progress
# Returns full step-by-step execution log with timestamps
💡This script is reusable! To dial a different number, simply edit the number field in the YAML script, then call run_script again. No code changes needed — the script is interpreted at runtime.
